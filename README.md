## 2. Sobre o projeto

O NexusTech é um site sobre tecnologia e inteligência artificial. A ideia foi criar um portal com conteúdos sobre aplicativos, mercado tecnológico e segurança digital, pegando a ideia de um trabalho que tinha iniciado em sala durante a aula, com o tema parecido "IA Noticias" Deixei o projeto/trabalho com a minha cara, do meu jeito, e minhas ideias.

O site possui quatro páginas: Início, Aplicativos, Mercado e Segurança. Cada uma apresenta conteúdos relacionados ao seu tema, com um menu para facilitar a navegação.

Também foi criado um painel para cadastrar e gerenciar notícias.

## 3. Tecnologias utilizadas

**HTML:** utilizado para criar as páginas, organizar os textos, imagens, menus e formulário.

**CSS:** utilizado para deixar o site organizado, definir as cores, os tamanhos e adaptar o layout para diferentes telas.

**JavaScript:** utilizado para criar a pesquisa por título, os botões de mostrar e ocultar detalhes e a validação do formulário de contato.

**PHP:** utilizado para criar o painel de gerenciamento de notícias, permitindo cadastrar, listar, editar e excluir informações.

**MySQL:** utilizado para armazenar as notícias em um banco de dados chamado `nexustech`.

**PDO:** utilizado para fazer a conexão entre o PHP e o banco de dados.

## 4. Como o trabalho foi desenvolvido

O trabalho foi desenvolvido sozinho, sem outros integrantes.

Primeiro, escolhi o tema de tecnologia e comecei a montar as páginas do site utilizando HTML. Depois, trabalhei na parte visual com CSS e adicionei algumas funcionalidades utilizando JavaScript.

Em seguida, decidi fazer também a parte extra em PHP. Para isso, criei um banco de dados no MySQL e desenvolvi um painel que permite gerenciar as notícias do site.

Durante o desenvolvimento, utilizei o VS Code para editar os arquivos e o XAMPP para executar e testar o projeto no computador.

## 6. Dificuldades e aprendizados

Uma das dificuldades foi fazer todas as páginas funcionarem corretamente e manter os arquivos organizados. A parte do PHP também achei mais dificil, precisei de mais atenção principalmente na configuração do banco de dados e na conexão utilizando PDO.

Com esse trabalho, consegui praticar melhor HTML, CSS e JavaScript, além de aprender um pouco mais sobre PHP, MySQL e como funciona um CRUD.

Também pude entender melhor como diferentes tecnologias podem ser utilizadas juntas para desenvolver um site.

## 7. Conclusão

O desenvolvimento do NexusTech foi uma oportunidade de colocar em prática o que foi aprendido durante a disciplina. Consegui criar um site com várias páginas, adicionar funcionalidades com JavaScript e desenvolver um painel de gerenciamento utilizando PHP e banco de dados.

Foi um trabalho que ajudou a melhorar meus conhecimentos em desenvolvimento web e a entender melhor como funciona a criação de um projeto completo.
